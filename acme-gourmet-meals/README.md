## Overview

Contributed to developing an expansion strategy for Acme Gourmet Meals using BART 
transit network data. Applied graph analytics to identify high-traffic hubs, optimal 
pickup locations, and faster local delivery zones.

## My Contribution

Applied Harmonic Centrality to BART transit data to identify the highest-traffic 
network hubs as optimal candidates for meal pickup locations and faster local 
delivery — implemented on AWS.

## Team Contributions

The full analysis combined multiple graph algorithms across the team:

| Algorithm | Purpose |
|-----------|---------|
| Harmonic Centrality *(mine)* | Identify high-traffic hubs |
| Louvain Modularity | Identify station communities |
| PageRank | Rank station importance |
| Minimum Spanning Tree | Optimize delivery network structure |
| Geodesic Fencing | Define optimal delivery zones |
