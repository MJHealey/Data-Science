# Social Media & Mental Health
`UC Berkeley · Aug 2024`

---

## Overview

Analyzed demographic, platform, and time spent usage patterns and emotional well-being 
trends across 1,248 social media users, building interactive Tableau visualizations and 
conducting usability testing to ensure accessibility for both technical and non-technical 
audiences.
